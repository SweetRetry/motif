**Motif** is a [shadcn registry](https://ui.shadcn.com/docs/registry) of interface parts for AI agents and generative media. Install components with `npx shadcn add` to own the source directly.

## What's in it

- **Agents** — `conversation`, `message`, `thinking-block`, `loading-state`, `prompt-input`, `voice-input`, `attachment`, `scroll-rail`, `approval-card`, `question-card`, `skill-detail`.
- **Components** — `ratio-picker`, `resolution-picker`, `duration-slider`, `generation-overlay`, `cover-fan`, `flow-edge`, `settings-dialog`, `activity-heatmap`.
- **Blocks** — `agent-run`.

## How the parts are built

- **Compound components** — A root owns the state and named parts compose it; empty slots and unhandled parts render nothing.
- **Theme tokens** — Every color uses shadcn tokens (`bg-card`, `text-muted-foreground`, `text-success`) and ships required tokens in `cssVars`.
- **[Motion](https://motion.dev/)** — Used for state transitions like thread auto-follow, loading waves, and card hover lift.
- **Agent ready** — Publishes `llms.txt`, `llms-full.txt`, an API catalog, and agent-skill discovery routes.

## Install

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/question-card.json
```

```tsx
import { QuestionCard } from "@/components/ui/motif/question-card";
```
