```bash
npx shadcn@latest add https://startercn.vercel.app/r/loading-state.json
```

## Usage

```tsx
import { LoadingState } from "@/components/ui/loading-state";

export function Answer() {
  if (pending) {
    return <LoadingState label="Thinking" />;
  }

  return <AnswerBody />;
}
```

The row counts from mount. Pass `startedAt` when the work outlived the component —
a request that was already in flight when the page mounted — and the duration picks up
where it really is:

```tsx
<LoadingState label="Summarising" startedAt={request.startedAt} />
```

## The wave

Nine cells, one cosine. A cell's phase is the anti-diagonal it sits on — `row + column` —
so the crest runs from the top-left corner to the bottom-right and back. There is no
per-cell tuning and no second animation: one sampled curve, nine start times.

A full cycle takes `WAVE_MS` (2000ms) to travel `WAVE_SPREAD` (5.5) diagonals. The lattice
only spans five of them, so a little under one whole wave is ever on screen — which is
what makes the pulse read as motion instead of nine cells blinking together. Cell opacity
runs between `CELL_TROUGH` (0.2) and `CELL_CREST` (0.6).

Every cell runs the same keyframes and `lead()` shifts where each one starts, by a _negative_
delay — park an animation part-way through its first cycle and the wave is already
travelling on the first frame, instead of easing in from a standstill. `LoadingGrid` is
exported on its own for when the text lives somewhere else — a toolbar, a button, a
viewport corner.

## The shimmer

The label is one span per letter, and each letter runs the grid's cosine offset by where
it sits in the word — the same wave, one dimension down. Two things are different, because
a word is not a lattice:

- **It runs on its own clock.** `LETTER_WAVE_MS` is 1400ms against the grid's 2000ms. A
  shimmer is read at the speed it crosses the word, and a short word crossed at the grid's
  tempo reads as a slow swell.
- **Its crest is pulled in.** `LETTER_FOCUS` raises the cosine to the third power before
  it is used. At `1` the bright half of the cycle is half the curve — wider than the word —
  so nothing appears to travel. At `3` it is a band about two letters wide with a rest on
  either side, crossed at `LETTER_MS` (130ms) per letter.

The trough stays at `0.55`, so the word is readable the whole way through, and that is the
whole trick — **the only property either wave touches is `opacity`**, which the compositor
owns. The previous version swept a gradient with `background-position` through a
`background-clip: text` element, which re-rasterises the glyph mask on the main thread
every frame — a tiny element that managed to stutter the whole page. Nothing here
repaints.

`ShimmerText` is exported on its own for any label that needs the treatment without the
rest of the row.

## The duration

`4s`, then `59s`, then `543s` — whole seconds, one unit, nothing to roll over.

Two mechanisms, doing two different jobs:

- **`tabular-nums`** stops a digit changing width. Proportional figures give `1` a
  narrower advance than `2`, so a second-by-second read-out reflows on the tick itself.
  Swapping in the tabular set makes every digit the same width, and the number is then
  rock-steady for its whole life.
- **One unit, no rollover** stops the read-out changing _shape_. `1m 0s` → `1m 10s` →
  `2m 0s` gains a character and hands it back every single minute; seconds-only has
  nothing to roll over. That leaves two steps, at ten seconds and at a hundred, and
  both are rare enough to live with.

That is a layout decision before it is a copy decision: a read-out that changes shape
moves the row.

It ticks on the second boundary rather than whenever a timer happens to fire, so the
number turns over when the second does.

The clock is written straight into the DOM by a ref rather than through state. A number
that re-renders a tree once a second is doing work for four characters, and a React commit
landing in the middle of a wave is exactly the kind of thing that turns a smooth animation
into a stutter. Nothing else moves either: the wave and the shimmer already carry the
motion, and a number sliding or rolling on top of them competes for the same attention.

Two clocks are on offer:

| Prop        | Behaviour                                                             |
| ----------- | --------------------------------------------------------------------- |
| `startedAt` | Epoch ms. The count runs from then, so a remount does not restart it. |
| `elapsed`   | Seconds, controlled. Wins over `startedAt` when you own the clock.    |

## Colour and size

The row sets its own tone instead of inheriting one. Everything inside is `currentColor`
— the cells are `bg-current`, the letters simply are the colour — so the tone has to be
resolved once, at the top. Left to inherit it, a loading row dropped into muted body copy
computes its whole palette off a grey and washes out; `text-foreground` is the floor, and
`className="text-primary"` recolours all of it. The duration keeps
`text-muted-foreground`, because it is the one part that is information.

One size ships, and it is fixed: 5px cells and 2.5px gutters, a 20px square beside a 14px
`text-sm` label and clock. The lattice runs well clear of the type on purpose — it is the
mark the row is recognised by, and the label and clock are only the caption under it.
Nothing inside is relative to the type around it, so a large heading can hold a loading row
without inflating it.

## Accessibility

The row is a `role="status"` live region holding the label and nothing else — the duration
is `aria-hidden`, since a polite region that announced it would read a new number every
second. The label itself is rendered twice: a clean copy for assistive tech, and the
split-into-letters one behind `aria-hidden`, because eight text nodes in a row is not
something to hand a screen reader. With no `label`, a visually hidden "Loading" takes its
place, and the grid is decorative throughout.

Under `prefers-reduced-motion` nothing animates and no time is spent on a loop: the grid
holds the wave at `t = 0`, the label sits at full tone, and the duration keeps counting,
because the count is the information.
