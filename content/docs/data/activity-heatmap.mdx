## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/activity-heatmap.json
```

## Usage

```tsx
import { ActivityHeatmap } from "@/components/ui/motif/activity-heatmap";

export function AgentActivity() {
  return <ActivityHeatmap className="text-chart-2" data={days} />;
}
```

```ts
const days = [
  { date: "2025-03-03", value: 14 },
  { date: "2025-03-04", value: 41 },
  { date: "2025-03-05", value: 0 },
];
```

- Plain `YYYY-MM-DD` strings are parsed as local calendar days (avoiding UTC midnight shifts); ISO timestamps are normalized to local midnight.
- Missing dates render as empty squares; data past `end` extends the grid rather than being dropped.

## Levels

- By default, levels 1–4 are quantiles of non-empty counts across the full dataset (level 4 at the 95th percentile), with ties placed in the lower level.
- Pass `thresholds` for fixed cutoffs, or set `level` directly on a datum to bypass calculation:

```tsx
// Fixed meaning: 1–4 runs is light, 40+ is the darkest.
<ActivityHeatmap data={days} thresholds={[4, 10, 20, 40]} />
```

```ts
{ date: "2025-03-04", value: 41, level: 4 }
```

## Range and geometry

| Prop           | Default | Does                                                     |
| -------------- | ------- | -------------------------------------------------------- |
| `weeks`        | `53`    | Columns of history; 53 is a year and a day               |
| `weekStartsOn` | `0`     | Which day a column starts on, `0` Sunday to `6` Saturday |
| `end`          | today   | The last day on the grid; data past it extends the range |
| `cellSize`     | `11`    | Side of a square, in px                                  |
| `gap`          | `3`     | Space between squares, in px — and around the grid       |

Items older than `weeks` columns are omitted from the grid; cells use fixed pixel dimensions and scroll horizontally when wider than their container.

## Colour

Defaults to `text-foreground` with an alpha ramp (12% empty; 26%, 46%, 70%, 100% for levels 1–4) so scales never invert between light and dark themes.

| Layer                | Set with    | Use it for                                        |
| -------------------- | ----------- | ------------------------------------------------- |
| `--heatmap-0` … `-4` | `style`     | a curated ramp, one level at a time               |
| `--heatmap-tint`     | `style`     | the whole ramp in one line, e.g. `var(--chart-3)` |
| `currentColor`       | `className` | the everyday case — any `text-*` token            |

```tsx
<ActivityHeatmap className="text-chart-2" data={days} />
```

```tsx
<ActivityHeatmap data={days} style={{ "--heatmap-tint": "var(--chart-2)" }} />
```

```tsx
<ActivityHeatmap
  data={days}
  style={{
    "--heatmap-0": "oklch(0.97 0 0)",
    "--heatmap-1": "oklch(0.87 0.08 150)",
    "--heatmap-2": "oklch(0.75 0.16 150)",
    "--heatmap-3": "oklch(0.6 0.16 150)",
    "--heatmap-4": "oklch(0.45 0.13 150)",
  }}
/>
```

## Tooltip and locale

| Prop          | Default                 | Does                              |
| ------------- | ----------------------- | --------------------------------- |
| `formatValue` | count, or "No activity" | The count in the tooltip          |
| `formatDate`  | `Mar 4, 2025`           | The date in the tooltip           |
| `locale`      | `en-US`                 | Month, weekday and date names     |
| `legend`      | `true`                  | The Less/More ramp under the grid |

```tsx
<ActivityHeatmap
  data={days}
  formatValue={(value) => `${value} tool calls`}
  formatDate={(date) => date.toDateString()}
/>
```

- Uses a single `fixed`-positioned DOM tooltip to avoid scroll-container clipping and per-cell re-renders; hides on scroll, pointer leave, or future dates.
- `locale` defaults to `"en-US"` rather than the browser locale to prevent SSR/client hydration mismatches.

## Accessibility & motion

- Renders as a semantic `<table>` (`<th scope="row">` for weekdays, `<th scope="colgroup">` for months, `sr-only` `<caption>`) with descriptive labels on each cell; cells are excluded from tab order.
- Mount animation staggers columns by 12ms (capped at 44 columns) and is disabled under `prefers-reduced-motion`.
