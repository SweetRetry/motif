## Usage

```tsx
import {
  Breakdown,
  BreakdownBar,
  BreakdownLegend,
  breakdownColors,
} from "@/components/ui/motif/breakdown";

const MODELS = [
  { key: "seedance-2-5", label: "Seedance 2.5", value: 486_200 },
  { key: "claude-sonnet-4-5", label: "Claude Sonnet 4.5", value: 312_450 },
  { key: "veo-3-1", label: "Veo 3.1", value: 184_900 },
];

const COLORS = breakdownColors(MODELS.map((model) => model.key));

export function ModelConsumption() {
  return (
    <Breakdown
      colors={COLORS}
      formatValue={(value) => `${value.toLocaleString()} pt`}
      items={MODELS}
    >
      <div className="flex flex-col gap-4">
        <BreakdownBar label="Consumption by model" />
        <BreakdownLegend />
      </div>
    </Breakdown>
  );
}
```

- `items` order is preserved (never sorted); items with `value <= 0` are omitted from both bar and legend, and empty datasets render nothing.
- `BreakdownBar` and `BreakdownLegend` can be used independently inside `<Breakdown>`.

## Props

| Prop          | Default        | Does                                         |
| ------------- | -------------- | -------------------------------------------- |
| `items`       | —              | The parts, in the order they should be drawn |
| `colors`      | —              | Each part's colour, keyed by `key`           |
| `total`       | sum of `items` | The whole the shares are read against        |
| `formatValue` | `12,400`       | The amount beside a label                    |
| `formatShare` | `42% of total` | The line in the tooltip                      |

- When `items` sum to less than `total`, the remaining track stays visible.
- `formatValue` and `formatShare` default to `en-US` formatting to avoid SSR hydration mismatches.

## Colour

`colors` is required; keys missing from the map fall back to `--muted-foreground`. `breakdownColors(keys)` assigns `--chart-1` through `--chart-5`, then steps lightness toward `--foreground` for up to 15 distinct hues. Pass the full catalog of keys to keep colors stable across filtered views:

```ts
const COLORS = breakdownColors(CATALOGUE.map((model) => model.key));
```

Or provide an explicit token map:

```ts
const COLORS = {
  "seedance-2-5": "var(--chart-1)",
  "claude-sonnet-4-5": "var(--chart-2)",
  "veo-3-1": "var(--chart-3)",
};
```

## Custom layout

`useBreakdown()` exposes the computed `items` (with `color` and `share`), `formatValue`, and `formatShare`:

</ComponentPreview>

```tsx
const Rows = () => {
  const { formatValue, items } = useBreakdown();

  return items.map((item) => (
    <div key={item.key}>
      {item.label}
      <span style={{ background: item.color, width: `${item.share}%` }} />
      {formatValue(item.value)}
    </div>
  ));
};

<Breakdown items={models}>
  <Rows />
</Breakdown>;
```

## Accessibility

- `BreakdownBar` uses `role="img"` with an accessible summary of all parts (prefixed by `label` when provided).
- `BreakdownLegend` renders `aria-hidden` color dots and `sr-only` share text; legend items are non-focusable.
