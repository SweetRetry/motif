## Usage

```tsx
import { CoverFan } from "@/components/ui/motif/cover-fan";

const PRESETS = [
  {
    id: "unbound-bloom",
    src: "/covers/unbound-bloom.webp",
    title: "Unbound Bloom",
  },
  { id: "refraction", src: "/covers/refraction.webp", title: "Refraction" },
  // …
];

export function EmptyState() {
  return (
    <CoverFan items={PRESETS} onSelect={(preset) => startSession(preset.id)} />
  );
}
```

- Each item accepts `{ id, title, src, alt? }`; `title` serves as the label and accessible name when `alt` is omitted. `onSelect` is required.

## Sizing & Geometry

Card width, pitch, drift, radius, and title size scale proportionally via CSS container queries (no `size` prop). Constrain width with `max-w-*` on the component or parent; `3–5` items is the recommended range, and titles floor at `11px`.

```tsx
<CoverFan className="max-w-xl" items={PRESETS} onSelect={pick} />
```

| Ratio                                 | Reference (`200 × 267`) | Effect                                                |
| ------------------------------------- | ----------------------- | ----------------------------------------------------- |
| `0.76` pitch                          | `152px`                 | Horizontal step per card                              |
| `0.067 / 0.127 / 0.015 / 0.052` drift | `18 / 34 / 4 / 14px`    | Repeating vertical offset                             |
| `2.5°` tilt                           | `±3.75°` (4 cards)      | Rotation scaling with distance from center            |
| `0.067` lift                          | `18px`                  | Vertical rise and `1.06` scale on hover/focus         |

## States

| State          | Behavior                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| Rest           | Overlapping fan left to right                                            |
| Lifted         | Hover/focus raises card `0.067` of height, resets tilt to `0°`, scales `1.06`, and raises `z-index` |
| Keyboard focus | Lifted state plus a visible focus ring                                   |

- One shared index drives both hover and focus; CSS transitions are disabled under `prefers-reduced-motion`.
