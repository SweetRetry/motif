## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/thinking-block.json
```

Add Streamdown's bundle to Tailwind's source scan:

```css
/* globals.css */
@source "../node_modules/streamdown/dist/*.js";
```

## Usage

```tsx
import { ThinkingBlock } from "@/components/ui/motif/thinking-block";

export function Reasoning({ thought }: { thought: Thought }) {
  return (
    <ThinkingBlock
      startedAt={thought.startedAt}
      streaming={thought.status === "streaming"}
    >
      {thought.text}
    </ThinkingBlock>
  );
}
```

## Behavior

- Capped at `208px` (`height` prop to override) with hidden scrollbars and `28px` top/bottom edge-fade masks updated directly in the DOM.
- Auto-follows wrapped lines via `translateY` animation when within `8px` of the bottom (`overflow-anchor` disabled); pauses if the user scrolls up and resumes on scroll down.
- Uses Streamdown in `streaming` mode while active and `static` mode when done (`controls` and `lineNumbers` off; import `"streamdown/styles.css"` if enabling Streamdown's `animated` option).
- Open by default (`defaultOpen`, `open`, `onOpenChange`); header button controls `AgentDisclosure`, and collapsed content is `inert` and `aria-hidden`.
- Uses [Loading State](/docs/agents/loading-state) while streaming; the `aria-hidden` clock updates directly in the DOM and freezes on the falling edge of `streaming` via `formatDuration` (`Xs`).
- Under `prefers-reduced-motion`, pins without `translateY` glide and swaps the chevron without rotating.

## Props

| Prop        | Behaviour                                                                           |
| ----------- | ----------------------------------------------------------------------------------- |
| `streaming` | Live row, follows its own tail, and holds the finished count when it stops.         |
| `startedAt` | Epoch ms the pass began, so a remount does not restart the count.                   |
| `duration`  | Seconds the pass took, when the caller owns the number. Wins in the finished label. |
| `label`     | What the row says while it waits. Defaults to `Thinking`.                           |
| `doneLabel` | What the finished pass is called. Defaults to `Thought`.                            |
