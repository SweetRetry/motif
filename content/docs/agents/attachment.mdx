## Usage

```tsx
import { Attachment } from "@/components/ui/motif/attachment";

export function Composer() {
  return (
    <div className="flex flex-wrap gap-4">
      <Attachment name="raven.jpg" src="/raven.jpg" onRemove={remove} />
      <Attachment name="payrollz.xlsx" progress={72} />
      <Attachment name="report.pdf" onRemove={remove} />
    </div>
  );
}
```

## Sizing

- Minimum width is `56px` with no `size` prop; internal dimensions scale proportionally via CSS container queries when given a larger width in `className`.

## States

`status` defaults to `"uploading"` while `progress < 100` and `"ready"` otherwise.

| Status      | Renders                                                                                 |
| ----------- | --------------------------------------------------------------------------------------- |
| `uploading` | Border progress arc (`primary`) and percentage; image previews fade toward `background` |
| `ready`     | Glyph + filename, or bare preview; shows remove button when `onRemove` is passed        |
| `error`     | Full border arc and filename in `text-destructive`                                      |

- The remove button stays hidden while `status === "uploading"`.

## Glyph

- Maps common extensions (`pdf`/`docx`/`txt`, `xlsx`/`csv`, `zip`/`tar`, `mp3`/`wav`, `mp4`/`mov`, `ts`/`js`, `json`, image formats) to matching icons, falling back to a generic page icon.
- Pass `icon` to override the glyph, or `src` to render an image thumbnail without a filename label.
