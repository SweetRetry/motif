## Usage

```tsx
import {
  ContextUsage,
  ContextUsageBar,
  ContextUsageLegend,
  ContextUsageRing,
  ContextUsageSummary,
} from "@/components/ui/motif/context-usage";
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@/components/ui/popover";

export function ContextMeter({ usage }) {
  return (
    <ContextUsage items={usage.items} limit={usage.window}>
      <Popover>
        <PopoverTrigger asChild>
          <button type="button">
            <ContextUsageRing showPercent />
          </button>
        </PopoverTrigger>
        <PopoverContent>
          <ContextUsageSummary />
          <ContextUsageBar />
          <ContextUsageLegend />
        </PopoverContent>
      </Popover>
    </ContextUsage>
  );
}
```

| Part                  | Role                                                    |
| --------------------- | ------------------------------------------------------- |
| `ContextUsage`        | Context provider taking `items`, `limit`, `nearAt`, and `colors` |
| `ContextUsageRing`    | Circular progress meter with optional percentage label  |
| `ContextUsageBar`     | Segmented bar sized against `limit` with free space as track |
| `ContextUsageLegend`  | Item list with color swatches and formatted token counts |
| `ContextUsageSummary` | Displays used/limit tokens, percentage, and remaining count |

## Tone & Colors

- `items` order assigns theme chart colors before zero-value items are omitted; pass `colors` to override.
- `tone` switches from `ok` (`foreground`) to `near` (`warning`, default `nearAt` 80%) to `full` (`destructive` at 100%). The ring arc caps at one full turn while percentage text continues above `100%`.

## Hook (`useContextUsage`)

```tsx
const CompactButton = () => {
  const { percent, tone } = useContextUsage();

  return tone === "ok" ? null : <button onClick={compact}>Compact</button>;
};
```

| Field          | Value                                        |
| -------------- | -------------------------------------------- |
| `used`         | Total tokens in `items`                      |
| `limit`        | Window token limit                           |
| `remaining`    | Tokens remaining, clamped at `0`             |
| `percent`      | Unrounded `used / limit` (`0–100+`)          |
| `tone`         | `"ok"`, `"near"`, or `"full"`                |
| `formatTokens` | Active token formatter                       |

## Formatting & Accessibility

- `formatTokens` defaults to `en-US` compact notation (`48.2K`) for SSR consistency; values under 1% display `<1%`.
- `ContextUsageRing` renders `role="meter"` (`0–100`) labeled `"Context used"`; wrap it in a `<button>` for interactive popovers. `ContextUsageBar` exposes an accessible label listing each item and size.
