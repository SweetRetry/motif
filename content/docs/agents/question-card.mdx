## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/question-card.json
```

Pulls in [`button`](https://ui.shadcn.com/docs/components/button), [`input`](https://ui.shadcn.com/docs/components/input), [`radio-group`](https://ui.shadcn.com/docs/components/radio-group), and `tooltip`, and adds the `warning` CSS variable (`:root`, `.dark`, `@theme`) for skipped steps. For yes/no confirmations, see [Approval Card](/docs/agents/approval-card).

## Usage

```tsx
import { QuestionCard } from "@/components/ui/motif/question-card";

export function Review() {
  return (
    <QuestionCard
      questions={[
        {
          id: "scope",
          title: "How focused should the first release be?",
          options: [
            { value: "focused", label: "A focused starter set" },
            { value: "broad", label: "A broader collection" },
          ],
        },
      ]}
      onAnswersChange={(answers) => console.log(answers)}
      onSubmit={(answers) => console.log("submitted", answers)}
    />
  );
}
```

## Status & Behavior

- Answers are stored in a map keyed by question `id`; picking a radio option clears the free-text field and typing clears the radio pick.
- Footer step bars jump to any question on click, preview it on hover, and mark skipped steps with `warning`.
- `Skip` and `Continue` allow moving past unanswered questions; `Submit` on the final step requires all questions to be answered.

| Status       | Meaning                                        |
| ------------ | ---------------------------------------------- |
| `pending`    | Waiting for the user, controls enabled         |
| `submitting` | Controls locked while the request is in flight |
| `answered`   | Done, no controls: `result` or the status text |
