```bash
npx shadcn@latest add https://motif.sweetretry.com/r/voice-input.json
```

## Usage

```tsx
import { VoiceInput } from "@/components/ui/motif/voice-input";

export function Composer() {
  return (
    <VoiceInput
      maxSeconds={120}
      onCancel={() => toast("Recording discarded.")}
      onRecord={(blob) => transcribe(blob)}
    />
  );
}
```

Omit `onRecord` and nothing is rendered.

## Behavior & Composing

- Press <kbd>Escape</kbd> to cancel recording; `VoiceBars` reads RMS levels via ref (`5x` gain) and updates `scaleY` directly in the DOM at 60fps without React re-renders (continues animating under `prefers-reduced-motion`).
- Exported `useVoiceRecorder`, `VoiceRecording`, and `VoiceBars` can be composed separately; pass `recorder` to `VoiceInput` to share state with an external `VoiceRecording` bar.

```tsx
import {
  useVoiceRecorder,
  VoiceBars,
  VoiceRecording,
} from "@/components/ui/motif/voice-input";

const { status, start, stop, cancel, readLevel, startedAt } = useVoiceRecorder({
  onRecord: (blob) => upload(blob),
});
```

## Props

### VoiceInput

| Prop         | Default | Meaning                                                                  |
| ------------ | ------- | ------------------------------------------------------------------------ |
| `onRecord`   | —       | Called with the finished recording; omit it and nothing is drawn         |
| `onCancel`   | —       | The recording was thrown away                                            |
| `maxSeconds` | `120`   | Auto-send at this many seconds                                           |
| `disabled`   | `false` | Takes the control out of the tab order and the pointer's reach           |
| `recorder`   | —       | A recorder from `useVoiceRecorder`, when the bar is drawn somewhere else |
| `className`  | —       | Extra classes for the control's box                                      |

### Parts

| Part               | Props                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------- |
| `useVoiceRecorder` | `onRecord`, `onCancel`, `maxSeconds` → `status`, `error`, `startedAt`, `start`, `stop`, `cancel`, `readLevel` |
| `VoiceRecording`   | `source`, `onCancel`, `onStop`, `className`                                                                   |
| `VoiceBars`        | `source`, `bars`, `className`                                                                                 |

`status` is `idle`, `requesting`, `recording`, `denied`, or `error`; `error` holds the message for the last two and clears when the next recording starts.
