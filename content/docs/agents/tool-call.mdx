## Usage

```tsx
import {
  ToolCall,
  ToolCallContent,
  ToolCallHeader,
  ToolCallName,
  ToolCallSection,
  ToolCallStatus,
  ToolCallSummary,
} from "@/components/ui/motif/tool-call";

export function ReadFile({ call }) {
  return (
    <ToolCall status={call.status}>
      <ToolCallHeader>
        <ToolCallStatus />
        <ToolCallName>read_file</ToolCallName>
        <ToolCallSummary>{call.input.path}</ToolCallSummary>
      </ToolCallHeader>
      <ToolCallContent>
        <ToolCallSection title="Input">{call.inputText}</ToolCallSection>
        <ToolCallSection title="Result">{call.resultText}</ToolCallSection>
      </ToolCallContent>
    </ToolCall>
  );
}
```

| Part              | Draws                                                 |
| ----------------- | ----------------------------------------------------- |
| `ToolCall`        | The column, the status, and the disclosure state      |
| `ToolCallHeader`  | The row; the control that opens the detail            |
| `ToolCallStatus`  | Where the call stands: ring, indicator, check, cross  |
| `ToolCallName`    | What was called, in mono                              |
| `ToolCallSummary` | The gist of the input, one line, cut with an ellipsis |
| `ToolCallContent` | The detail, behind a disclosure                       |
| `ToolCallSection` | A labelled block inside the detail                    |
| `useToolCall`     | Status, open state and toggle, for a part of your own |

## Status

| Status     | Draws                                      |
| ---------- | ------------------------------------------ |
| `queued`   | An empty ring; the row is dimmed           |
| `approval` | An amber dot, in `warning`; waiting on you |
| `running`  | The loading mark                           |
| `done`     | A check, in `success`                      |
| `failed`   | A cross, in `destructive`                  |

- Reuses [Loading State](/docs/agents/loading-state) for `running`; pass `label` to `ToolCallStatus` to translate screen-reader status names.
- Pair `approval` with an [Approval Card](/docs/agents/approval-card) below the row while waiting for confirmation.

## Detail & Controlled State

```tsx
<ToolCallContent>
  <ToolCallSection title="3 results">
    <Sources sources={call.sources} />
  </ToolCallSection>
</ToolCallContent>

<ToolCallContent>
  <ToolCallSection>
    <ImageGrid images={call.images} />
  </ToolCallSection>
</ToolCallContent>
```

```tsx
<ToolCallSection title="Error">
  <p className="text-destructive text-xs">{call.error}</p>
</ToolCallSection>
```

- Without `ToolCallContent`, `ToolCallHeader` renders as a plain non-interactive row without a chevron.
- `ToolCallSection` renders string children as preformatted text (capped at `12rem`), renders nothing when empty, and omits the heading when `title` is omitted (e.g. for [Source](/docs/agents/source) lists or images).
- Supports `defaultOpen`, `open`, and `onOpenChange` (e.g. `open={status === "failed"}`).
