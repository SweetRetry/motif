## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/approval-card.json
```

Pulls in [`button`](https://ui.shadcn.com/docs/components/button) and [`input`](https://ui.shadcn.com/docs/components/input). For multi-option prompts, see [Question Card](/docs/agents/question-card).

## Usage

```tsx
import { ApprovalCard } from "@/components/ui/motif/approval-card";

export function Review() {
  return (
    <ApprovalCard
      onApprove={() => console.log("approved")}
      onReject={(reason) => console.log("rejected", reason)}
    >
      This tool wants to delete the file <code>/tmp/example.txt</code>. Do you
      approve this action?
    </ApprovalCard>
  );
}
```

## Props & Behavior

| Prop           | Description                                                |
| -------------- | ---------------------------------------------------------- |
| `children`     | Action summary; inline `<code>` elements render as chips   |
| `onApprove`    | Renders the approve button when provided                   |
| `onReject`     | Renders the reject button when provided; receives optional reason string |
| `approveLabel` | Custom label for the approve button                        |
| `rejectLabel`  | Custom label for the reject button                         |
| `submitting`   | Disables both action buttons while a decision is in flight |

- Pressing Reject opens an inline reason input in place of the buttons; `Enter` calls `onReject(reason)` and `Escape` returns to the buttons.
- Designed to mount under a [Tool Call](/docs/agents/tool-call) in the `approval` status and unmount once the call moves on.
- Uses `bg-card` with a border so it separates cleanly from `bg-background` and `bg-muted`.
