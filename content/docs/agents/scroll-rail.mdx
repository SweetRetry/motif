## Usage

`focus` is a continuous number from `0` (first tick) to `items.length - 1` (last tick).

```tsx
import { useRef } from "react";

import {
  ScrollRail,
  ScrollRailPreview,
} from "@/components/ui/motif/scroll-rail";
import { useMessageFocus } from "@/hooks/use-scroll-focus";

export function Transcript() {
  const scroller = useRef<HTMLDivElement>(null);
  const nodes = useRef<(HTMLElement | null)[]>([]);
  const focus = useMessageFocus(scroller, nodes);

  return (
    <div className="flex gap-4">
      <ScrollRail
        focus={focus}
        label="Transcript"
        items={messages.map((message) => ({
          id: message.id,
          label: message.question,
          preview: (
            <ScrollRailPreview title={message.question}>
              {message.answer}
            </ScrollRailPreview>
          ),
        }))}
        onSelect={(index) =>
          nodes.current[index]?.scrollIntoView({ block: "center" })
        }
      />
      <div ref={scroller} className="h-96 overflow-y-auto">
        {messages.map((message, index) => (
          <article
            key={message.id}
            ref={(node) => {
              nodes.current[index] = node;
            }}
          >
            {message.answer}
          </article>
        ))}
      </div>
    </div>
  );
}
```

## Focus

Both focus hooks return a motion value so scrolling updates styles without re-rendering React.

| Mode     | Hook                                           | Reading line                                                                     |
| -------- | ---------------------------------------------- | -------------------------------------------------------------------------------- |
| Item     | `useMessageFocus(scroller, nodes, { offset })` | Interpolates between neighbouring item centres relative to `offset` (`0`–`1`)    |
| Progress | `useScrollProgress(scroller, { count })`       | Maps total scrolled distance across `count` ticks                                |

`offset` sets the reading line inside the viewport (`0` top, `0.5` center, `1` bottom); scroll ends are anchored so the first and last ticks remain reachable.

## Props & Styling

Ticks use `bg-current`, so `className="text-primary"` recolors the rail.

| Prop                      | Default     | Meaning                                                                    |
| ------------------------- | ----------- | -------------------------------------------------------------------------- |
| `pitch`                   | `10`        | Vertical distance between ticks, in px                                     |
| `thickness`               | `2`         | Tick thickness, in px                                                      |
| `minLength` / `maxLength` | `10` / `28` | Resting and focused tick length, in px                                     |
| `spread`                  | `1.35`      | Width falloff, in ticks                                                    |
| `highlight`               | `0.45`      | Colour falloff, in ticks                                                   |
| `minOpacity`              | `0.2`       | Opacity at the far end                                                     |
| `side`                    | `"left"`    | Which edge the rail sits on; flips the grow direction and the popover side |

## Interaction & Accessibility

- Without `onSelect` or `preview`, the rail is a non-interactive, `aria-hidden` read-out.
- Hover previews are gated behind `useHoverCapable` with open/close delays, and keyboard `:focus-visible` holds previews open.
- Single tab stop: arrow keys, <kbd>Home</kbd>, and <kbd>End</kbd> move between ticks with `aria-current`; handle `prefers-reduced-motion` when scrolling on `onSelect`.
