## Usage

```tsx
import {
  Source,
  SourceLabel,
  SourceList,
  SourceMark,
} from "@/components/ui/motif/source";

export function Sources({ sources }) {
  return (
    <SourceList>
      {sources.map((source) => (
        <Source href={source.url} key={source.url} title={source.title}>
          <SourceMark />
          <SourceLabel />
        </Source>
      ))}
    </SourceList>
  );
}
```

| Part          | Draws                                                          |
| ------------- | -------------------------------------------------------------- |
| `Source`      | The tag: a link opening in a new tab, with the title on hover  |
| `SourceMark`  | A small square: the site's icon if you pass one, else a letter |
| `SourceLabel` | What the tag says, the host unless you pass something else     |
| `SourceList`  | Tags side by side, wrapping                                    |
| `useSource`   | The `href` and the host, for a part of your own                |

## Host & Label

`Source` parses the hostname from `href` (stripping `www.`, or printing unparseable URLs as-is); pass children to `SourceLabel` to override, and omit `title` to render a plain link without a tooltip.

```tsx
<SourceLabel>Example Docs</SourceLabel>
```

## Mark

`SourceMark` defaults to Google's favicon service (`32px` fetched, `14px` rendered) and falls back to the host's first letter when `src={false}` or image loading fails.

```tsx
<SourceMark /> // the host's favicon
<SourceMark src={source.icon} /> // an icon you serve yourself
<SourceMark src={false} /> // the host's first letter, no request
```

## In a tool call

Pair `Sources` with [Tool Call](/docs/agents/tool-call) to display search results:

```tsx
<ToolCall status="done">
  <ToolCallHeader>
    <ToolCallStatus />
    <ToolCallName>web_search</ToolCallName>
    <ToolCallSummary>{call.query}</ToolCallSummary>
  </ToolCallHeader>
  <ToolCallContent>
    <ToolCallSection title={`${call.sources.length} results`}>
      <Sources sources={call.sources} />
    </ToolCallSection>
  </ToolCallContent>
</ToolCall>
```

## Accessibility

Renders as an external link (`target="_blank"` with `noreferrer noopener`) with `aria-hidden` on `SourceMark`; put essential context in `SourceLabel` rather than relying on the `title` tooltip.
