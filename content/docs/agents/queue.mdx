## Usage

```tsx
import {
  Queue,
  QueueHeader,
  QueueItem,
  QueueItemMarker,
  QueueItemRemove,
  QueueItemSendNow,
  QueueItemText,
  QueueList,
} from "@/components/ui/motif/queue";

export function Waiting({ messages, onRemove, onSendNow }) {
  return (
    <Queue>
      <QueueHeader>{messages.length} queued</QueueHeader>
      <QueueList>
        {messages.map((message) => (
          <QueueItem key={message.id}>
            <QueueItemMarker />
            <QueueItemText>{message.text}</QueueItemText>
            <QueueItemSendNow onClick={() => onSendNow(message.id)} />
            <QueueItemRemove onClick={() => onRemove(message.id)} />
          </QueueItem>
        ))}
      </QueueList>
    </Queue>
  );
}
```

| Part               | Draws                                                  |
| ------------------ | ------------------------------------------------------ |
| `Queue`            | The card the rows sit in; nothing while it has no rows |
| `QueueHeader`      | A line above the rows, for the count                   |
| `QueueList`        | The rows, as an ordered list (`ol`)                    |
| `QueueItem`        | One waiting message                                    |
| `QueueItemMarker`  | Marker icon for queued order                           |
| `QueueItemText`    | Single-line message text                               |
| `QueueItemSendNow` | Button to send the message immediately                 |
| `QueueItemRemove`  | Button to remove the message from the queue            |

## Behavior

- Stateless and ordered by children; `Queue`, `QueueHeader`, and `QueueItemText` render nothing when empty.
- `QueueItemSendNow` and `QueueItemRemove` render only when `onClick` is provided.
- Action buttons are hidden until hover or keyboard focus on desktop and always visible on touch screens.
- Pass `children` to `QueueItemSendNow` (default `"Send now"`) or `aria-label` to `QueueItemRemove` (default `"Remove from queue"`) to customize labels.
