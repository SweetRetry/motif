## Usage

```tsx
import {
  SkillCard,
  SkillDetailDialog,
} from "@/components/ui/motif/skill-detail";

export function Library({ skills }: { skills: Skill[] }) {
  const [openId, setOpenId] = useState<string | null>(null);
  const open = skills.find((skill) => skill.id === openId);

  return (
    <>
      <div className="grid grid-cols-2 gap-4 sm:grid-cols-3">
        {skills.map((skill) => (
          <SkillCard
            cover={skill.cover}
            description={skill.summary}
            key={skill.id}
            onOpen={() => setOpenId(skill.id)}
            title={skill.name}
          />
        ))}
      </div>

      {open ? (
        <SkillDetailDialog
          author={open.author}
          cover={open.cover}
          description={open.description}
          files={open.files}
          folder={open.slug}
          onOpenChange={(next) => setOpenId(next ? open.id : null)}
          open
          prompts={open.prompts}
          results={open.results}
          renderPreview={(file) => (
            <Markdown source={read(open.id, file.path)} />
          )}
          tags={open.tags}
          title={open.name}
        />
      ) : null}
    </>
  );
}
```

## Parts

- `SkillCard`: Summary card with a 16:9 cropped cover, title, and clamped description; pass `href` instead of `onOpen` to navigate to a dedicated route.
- `SkillDetail`: Two-column panel that fills its container height and switches to a top banner layout below `48rem` via a container query; ship a portrait `cover` for the rail.
- `SkillDetailDialog`: Dialog wrapper sized to `min(46rem, 88dvh)` and `max-w-5xl` that wires `onClose` and supports controlled (`open` / `onOpenChange`) or uncontrolled (`defaultOpen`) state.

## Workspace & Files

- `results` and `prompts` render in the first tab (`resultsLabel`, default `"Results"`) and `files` in the second; if only one exists, the tab strip is omitted.
- Example prompt rows only render as buttons when `onPrompt` is provided; toolbar `onClose` and `menu` controls only render when passed.
- `files` accepts slash-delimited paths in display order (unsorted); `folder` sets the collapsed root, and the first file is selected by default (`selectedPath` / `onFileSelect` to control).
- `renderPreview` renders the selected `SkillFile` (omit for a single-column manifest); `SkillCode` is exported for unstyled read-only code blocks with copy.

```tsx
<div className="flex flex-col gap-6">
  <SkillCode code={frontMatter} language="YAML" />
  <Markdown source={body} />
</div>
```

## Keyboard & Motion

- File tree uses roving focus: <kbd>ArrowUp</kbd>/<kbd>ArrowDown</kbd> move rows, <kbd>ArrowRight</kbd> opens or enters a folder, <kbd>ArrowLeft</kbd> closes or steps out, <kbd>Home</kbd>/<kbd>End</kbd> jump to ends, and <kbd>Enter</kbd>/<kbd>Space</kbd> toggle or select.
- Respects `prefers-reduced-motion` by disabling folder height and preview fade animations.

## Props

| Region   | Prop                            | Notes                                                             |
| -------- | ------------------------------- | ----------------------------------------------------------------- |
| Card     | `cover`, `title`, `description` | The summary: one line, clamped to two, cover at 16:9              |
| Card     | `onOpen` / `href`               | Opens in place, or navigates when the skill has a page            |
| Identity | `tags`, `title`, `author`       | The heading is the only required prop                             |
| Identity | `cover`                         | The rail's background, cropped; portrait crop                     |
| Identity | `updatedAt`                     | Already formatted — the panel does not touch dates                |
| Action   | `onTry` / `tryLabel`            | The last thing in the rail, full width; needs a handler           |
| Identity | `description`                   | In the rail; narrow, under the banner                             |
| Results  | `results`, `resultsNote`        | First tab: the work the skill made, and where it came from        |
| Results  | `resultsLabel`                  | Name of the first tab, `"Results"` by default                     |
| Prompts  | `prompts` / `promptsLabel`      | First tab, under the results; rows become buttons with `onPrompt` |
| Toolbar  | `enabled` / `defaultEnabled`    | Passing either draws the switch, controlled or not                |
| Toolbar  | `menu`                          | Slot for a "…" dropdown; the panel ships no menu of its own       |
| Files    | `files`, `folder`               | Paths in; the tree is built for you                               |
| Files    | `renderPreview`                 | The only part of the tree the panel does not draw                 |
| Dialog   | `open` / `onOpenChange`         | Uncontrolled with `defaultOpen`, like the panel's selection       |
