
## Usage

```tsx
import {
  LoadingState,
  LoadingStateClock,
  LoadingStateLabel,
  LoadingStateMark,
} from "@/components/ui/motif/loading-state";

<LoadingState>
  <LoadingStateMark />
  <LoadingStateLabel>Churning</LoadingStateLabel>
  <LoadingStateClock />
</LoadingState>;
```

| Part                | Role                                                       |
| ------------------- | ---------------------------------------------------------- |
| `LoadingState`      | Root `role="status"` row; parts are independent and optional |
| `LoadingStateMark`  | 3×3 opacity-animated grid (`text-foreground` by default)   |
| `LoadingStateLabel` | Status word                                                |
| `LoadingStateClock` | Elapsed timer                                              |

## Behavior & Accessibility

- `LoadingStateMark` animates opacity only and freezes on the first frame under `prefers-reduced-motion`; override its color with a `text-*` class.
- `LoadingStateClock` updates at 10Hz directly in the DOM without React re-renders, flooring tenths under 1 minute (`46.8s`) and switching to whole seconds after (`1m 05s`).
- Pass `startedAt` (epoch ms) to `LoadingStateClock` to preserve elapsed time across remounts.
- `LoadingState` uses `role="status"` while the mark and clock are `aria-hidden` so screen readers announce the label once without timer chatter.
