## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/agent-activity.json
```

Built on [Loading State](/docs/agents/loading-state); steps typically compose [Tool Call](/docs/agents/tool-call) and [Thinking Block](/docs/agents/thinking-block).

## Usage

```tsx
import {
  AgentActivity,
  AgentActivityContent,
  AgentActivityHeader,
  AgentActivityTitle,
} from "@/components/ui/motif/agent-activity";

export function Run({ run }) {
  return (
    <AgentActivity
      duration={run.seconds}
      running={run.running}
      startedAt={run.startedAt}
    >
      <AgentActivityHeader>
        <AgentActivityTitle />
      </AgentActivityHeader>
      <AgentActivityContent>
        {run.steps.map((step) => (
          <Step key={step.id} step={step} />
        ))}
      </AgentActivityContent>
    </AgentActivity>
  );
}
```

| Part                   | Role                                                         |
| ---------------------- | ------------------------------------------------------------ |
| `AgentActivity`        | Root state provider for `running`, `duration`, and open state |
| `AgentActivityHeader`  | Toggle button that expands or collapses the timeline         |
| `AgentActivityTitle`   | Renders `LoadingState` while running, or `Worked for {duration}s` once stopped |
| `AgentActivityContent` | Collapsible step container indented beneath the header       |

## Props

| Prop           | Description                                                |
| -------------- | ---------------------------------------------------------- |
| `running`      | Shows the live loading title and auto-opens when `defaultOpen` is unset |
| `duration`     | Elapsed seconds shown after completion (renders `Worked` if omitted) |
| `startedAt`    | Epoch ms timestamp so remounting preserves the running clock |
| `defaultOpen`  | Initial open state; defaults to matching `running`         |
| `open`         | Controlled open state                                      |
| `onOpenChange` | Called when the header is toggled                          |

## Behavior & Accessibility

- Once the user toggles the header, auto-folding on completion is bypassed; a run with no steps stays closed and omits the chevron.
- `useAgentActivity()` returns `{ running, duration, isOpen, toggle }` for custom child controls.
- `AgentActivityHeader` renders a `<button>` with `aria-expanded` and `aria-controls`; the running title is a live region with the clock hidden from screen readers, and folded content is `inert`.
