## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/conversation.json
```

Uses [`button`](https://ui.shadcn.com/docs/components/button) at its icon size.

## Usage

```tsx
import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from "@/components/ui/motif/conversation";
import { Message, MessageContent } from "@/components/ui/motif/message";

export function Thread({ turns }: { turns: Turn[] }) {
  return (
    <Conversation>
      <ConversationContent className="gap-6 px-4 py-6">
        {turns.map((turn) => (
          <Message from={turn.from} key={turn.id}>
            <MessageContent>{turn.text}</MessageContent>
          </Message>
        ))}
      </ConversationContent>

      <ConversationScrollButton />
    </Conversation>
  );
}
```

| Part                       | Role                                                               |
| -------------------------- | ------------------------------------------------------------------ |
| `Conversation`             | Root container managing scroll-follow state (`flex-1 min-h-0`)     |
| `ConversationContent`      | Scrolling viewport; render exactly one directly inside `Conversation` |
| `ConversationScrollButton` | Jump-to-bottom button mounted only when scrolled away from the end |
| `useConversation`          | Returns `{ atEnd, scrollToEnd }` for custom controls               |

## Behavior & Layout

- `MutationObserver` and `ResizeObserver` update `scrollTop` on `requestAnimationFrame` directly in the DOM without React re-renders; scrolling within `24px` of the bottom counts as at-end.
- Opens pinned to the bottom before first paint.
- `ConversationScrollButton` smooth-scrolls to the end, or jumps immediately under `prefers-reduced-motion`, and carries an `aria-label`.
- Place inside a flex column or give `Conversation` an explicit height (e.g. `h-96` or `h-dvh`).

```tsx
<div className="flex h-dvh flex-col">
  <Conversation>…</Conversation>
</div>
```
