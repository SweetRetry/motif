## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/diff.json
```

## Usage

```tsx
import {
  Diff,
  DiffContent,
  DiffFile,
  DiffHeader,
  DiffStat,
} from "@/components/ui/motif/diff";

export function FileChange({ patch }) {
  return (
    <Diff patch={patch}>
      <DiffHeader>
        <DiffFile />
        <DiffStat />
      </DiffHeader>
      <DiffContent />
    </Diff>
  );
}
```

| Part           | Role                                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| `Diff`         | Root frame accepting either `patch` or `before`/`after`                       |
| `DiffHeader`   | Optional header row; renders nothing when empty                               |
| `DiffFile`     | Displays path from `patch` `+++` header or `file` prop                        |
| `DiffStat`     | Displays `+N −M` counts, omitting zero sides                                  |
| `DiffContent`  | Renders diff lines with gutter numbers, markers, and inline word highlights   |
| `useDiff`      | Returns parsed lines, counts, and path for custom subcomponents               |
| `parsePatch`   | Standalone patch parser returning lines, counts, and path                     |
| `compareTexts` | Standalone `before`/`after` diff helper using `jsdiff`                        |

## Inputs

Pass either `patch` or `before`/`after`, never both.

```tsx
<Diff patch={call.patch}>…</Diff>

<Diff before={call.old_string} after={call.new_string} firstLine={call.line}>
  …
</Diff>
```

- `firstLine` sets the starting line number for `before`/`after` diffs (pass `1` for full files; omit to hide the gutter). Unchanged stretches over 3 lines fold into a marker row.
- `patch` accepts full `git diff` headers (`diff --git`, `index`, `---`/`+++`, `@@`) or bare `+`/`-`/space lines; `\ No newline at end of file` is stripped.
- Gutter `+`/`-` markers are non-selectable so copied text contains only code.

## Styling & Accessibility

- Uses `success` and `destructive` tokens (`10%` line tint, `25%` word highlight); installing adds `success` CSS variables to `:root`, `.dark`, and `@theme`.
- Renders inside `<pre>` with `+`/`-` markers exposed to screen readers, line numbers hidden, and `DiffStat` labeled `"N added, M removed"`.
