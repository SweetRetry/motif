## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/prompt-input.json
```

Pulls in [attachment](https://motif.sweetretry.com/docs/agents/attachment) and `dropdown-menu`; `PromptInputEditor` and `PromptInputTrigger` also include [Tiptap](https://tiptap.dev).

## Usage

```tsx
import { useState } from "react";

import {
  ModelPicker,
  PromptInput,
  PromptInputAttach,
  PromptInputAttachment,
  PromptInputFooter,
  PromptInputHeader,
  PromptInputSubmit,
  PromptInputTextarea,
  type PromptAttachment,
  type PromptModel,
} from "@/components/ui/motif/prompt-input";

const MODELS: PromptModel[] = [
  { id: "gpt-5.2", name: "GPT-5.2", provider: "openai" },
  { id: "claude-sonnet-4.5", name: "Claude Sonnet 4.5", provider: "anthropic" },
  { id: "gemini-3-pro", name: "Gemini 3 Pro", provider: "gemini" },
];

export function Composer() {
  const [model, setModel] = useState(MODELS[0].id);
  const [attachments, setAttachments] = useState<PromptAttachment[]>([]);

  return (
    <PromptInput onSubmit={(message) => send({ message, model })}>
      <PromptInputHeader>
        {attachments.map(({ id, ...chip }) => (
          <PromptInputAttachment
            key={id}
            {...chip}
            onRemove={() =>
              setAttachments((current) =>
                current.filter((file) => file.id !== id)
              )
            }
          />
        ))}
      </PromptInputHeader>

      <PromptInputTextarea placeholder="Review the current implementation and suggest the next improvement." />

      <PromptInputFooter>
        <PromptInputAttach onFiles={(files) => upload(files, setAttachments)} />
        <ModelPicker models={MODELS} onValueChange={setModel} value={model} />
        <PromptInputSubmit />
      </PromptInputFooter>
    </PromptInput>
  );
}
```

Uncontrolled drafts clear on submit; pass `value` and `onValueChange` to control the draft yourself (`onSubmit` receives trimmed text).

## Parts

| Part                    | Role                                                                         |
| ----------------------- | ---------------------------------------------------------------------------- |
| `PromptInput`           | Root card, draft state, and submit contract                                  |
| `PromptInputHeader`     | Flex row above the field; renders nothing when empty                         |
| `PromptInputTextarea`   | Auto-growing textarea with two-line floor and Enter binding                  |
| `PromptInputEditor`     | Rich-text document field for mentions and slash commands                     |
| `PromptInputTrigger`    | Trigger character and menu config inside `PromptInputEditor`                 |
| `PromptInputFooter`     | Flex row below the field                                                     |
| `PromptInputAttachment` | Animated [attachment](https://motif.sweetretry.com/docs/agents/attachment) chip |
| `PromptInputButton`     | Platform [`button`](https://ui.shadcn.com/docs/components/button) at `size-10 rounded-full` |
| `PromptInputAttach`     | File picker button; renders nothing without `onFiles`                        |
| `PromptInputSubmit`     | Submit or stop button; disabled when the draft is empty                      |
| `ModelPicker`           | Standalone model selector                                                    |

- `PromptInputTextarea`, `PromptInputEditor`, `PromptInputAttach`, and `PromptInputSubmit` read root context and must sit inside `PromptInput`.
- The field starts at two lines, grows up to `maxHeight` (`200px` default), and then scrolls.
- <kbd>Enter</kbd> submits, <kbd>Shift</kbd>+<kbd>Enter</kbd> inserts a newline, and IME composition <kbd>Enter</kbd> is ignored.

```tsx
<PromptInput onSubmit={(text, segments) => send(segments)}>
  <PromptInputEditor placeholder="Type @ to point at a file, / to run a command.">
    <PromptInputTrigger char="@" items={files} />
    <PromptInputTrigger
      char="/"
      items={commands}
      lineStart
      onSelect={(item) => (item.id === "clear" ? false : undefined)}
    />
  </PromptInputEditor>
  <PromptInputFooter>
    <PromptInputSubmit />
  </PromptInputFooter>
</PromptInput>
```

- `PromptInputTrigger` configures a trigger character (`lineStart` restricts it to line start; `items` accepts an array or search function).
- Arrow keys navigate, <kbd>Enter</kbd> or <kbd>Tab</kbd> selects, <kbd>Escape</kbd> closes, and returning `false` from `onSelect` runs the command without inserting text.
- `onSubmit` receives `(text, segments)` where mentions keep their `id`; setting `value` externally resets the document to plain text.

```ts
type PromptSegment =
  | { type: "text"; text: string }
  | { type: "mention"; trigger: string; id: string; label: string };
```

## Models

`ModelPicker` accepts `{ id, name, provider }[]` (controlled via `value`/`onValueChange` or uncontrolled via `defaultValue`) and opens upward. `ProviderLogo` (from [Provider Logo](/docs/media/provider-logo)) and `PROVIDER_NAMES` are re-exported; monochrome marks inherit `text-*` color classes while colored marks ignore them.

```tsx
import { ProviderLogo } from "@/components/ui/motif/provider-logo";

<ProviderLogo className="size-5 text-foreground" provider="anthropic" />;
```

## Streaming

- Passing `streaming` swaps `PromptInputSubmit` to a stop button (`onStop`) and blocks <kbd>Enter</kbd> submission.
- Pass `onQueue` to queue drafts on <kbd>Enter</kbd> while streaming (e.g. for [Queue](/docs/agents/queue)).

## Props

### PromptInput

| Prop            | Default | Meaning                                                                             |
| --------------- | ------- | ----------------------------------------------------------------------------------- |
| `value`         | —       | Controlled draft, never cleared by a send                                           |
| `defaultValue`  | `""`    | Draft the composer starts with                                                      |
| `onValueChange` | —       | Called with the draft on every change                                               |
| `onSubmit`      | —       | Called with the trimmed draft and its segments; <kbd>Enter</kbd> or submit          |
| `streaming`     | `false` | Swaps the submit part's arrow for stop, and blocks <kbd>Enter</kbd>                 |
| `onStop`        | —       | Called when the stop face is pressed                                                |
| `onQueue`       | —       | Under `streaming`, called with the draft on <kbd>Enter</kbd> in place of `onSubmit` |
| `disabled`      | `false` | Disables the field and the submit button                                            |
| `className`     | —       | Extra classes for the card                                                          |

Extra props pass through to the underlying `form`.

### Parts

| Part                                      | Props                                                                       |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| `PromptInputTextarea`                     | `maxHeight`, plus `textarea` props; `onKeyDown` runs before the binding     |
| `PromptInputEditor`                       | `maxHeight`, `placeholder`, plus `div` props; `PromptInputTrigger` children |
| `PromptInputTrigger`                      | `char`, `items`, `lineStart`, `onSelect`                                    |
| `PromptInputAttachment`                   | `AttachmentProps` — `name`, `src`, `progress`, `status`, `icon`, `onRemove` |
| `PromptInputAttach`                       | `onFiles`, `accept`, plus `ButtonProps`                                     |
| `PromptInputSubmit`                       | `ButtonProps`; `className` lands on the button                              |
| `PromptInputButton`                       | `ButtonProps` — `variant`, `size`, `sound`, `haptic`; geometry fixed        |
| `PromptInputHeader` / `PromptInputFooter` | `div` props                                                                 |
| `ModelPicker`                             | `models`, `value`, `defaultValue`, `onValueChange`, `className`             |
