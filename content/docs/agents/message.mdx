## Usage

```tsx
import {
  Message,
  MessageActions,
  MessageContent,
} from "@/components/ui/motif/message";

export function Turn({ turn }: { turn: Turn }) {
  return (
    <Message from={turn.from}>
      <MessageContent>
        {turn.text}
        <MessageActions>
          <CopyButton value={turn.text} />
        </MessageActions>
      </MessageContent>
    </Message>
  );
}
```

| Part             | Role                                                                |
| ---------------- | ------------------------------------------------------------------- |
| `Message`        | Root row; sets `data-from` and alignment from `from`                |
| `MessageContent` | Body container styled by role from context                          |
| `MessageActions` | Action row revealed on `:hover` or `:focus-within`; hidden if empty |

## Roles & Behavior

| `from`        | Root alignment | `MessageContent` styling                  |
| ------------- | -------------- | ----------------------------------------- |
| `"user"`      | Row reversed   | `bg-muted` bubble, `max-w-[85%]`, preserves whitespace |
| `"assistant"` | Row as written | Full width, no fill                       |
| `"system"`    | Centered       | Muted, centered                           |

- Custom `from` values are supported via the `data-from` attribute on `Message`.
- `MessageActions` uses CSS `:hover` and `:focus-within` for reveal so keyboard focus and touch taps work without JS hover detection.
