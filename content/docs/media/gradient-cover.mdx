## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/gradient-cover.json
```

## Usage

```tsx
import {
  GradientCover,
  GradientCoverTitle,
} from "@/components/ui/motif/gradient-cover";

export function CollectionCard({ collection }) {
  return (
    <GradientCover seed={collection.id}>
      <GradientCoverTitle>{collection.name}</GradientCoverTitle>
    </GradientCover>
  );
}
```

`seed` is required and deterministically picks `palette` and `pattern` when omitted.

## Variants

<GradientCoverMatrixDemo />

| Pattern  | Draws                                                      |
| -------- | ---------------------------------------------------------- |
| `plain`  | Nothing (color and grain only)                             |
| `waves`  | Near-parallel lines whose swell grows down the cover       |
| `dots`   | Fixed grid of dots                                         |
| `petals` | Leaf outlines scattered across the cover and off its edges |

## Seeds

Fixing `palette` or `pattern` leaves the other axis's seeded output unchanged.

## As an image source

`gradientCoverUrl` returns a `data:` URI and `gradientCoverSvg` returns the raw SVG string, for use with components like [Cover Fan](/docs/agents/cover-fan).

```tsx
import { gradientCoverUrl } from "@/components/ui/motif/gradient-cover";

const items = starters.map((starter) => ({
  id: starter.id,
  title: starter.title,
  src: gradientCoverUrl({ seed: starter.id, palette: "lagoon" }),
}));

<CoverFan items={items} onSelect={start} />;
```

<GradientCoverFanDemo />

## Parts

| Part                 | Renders                                                     |
| -------------------- | ----------------------------------------------------------- |
| `GradientCover`      | Root container (`rounded-xl` square by default) and SVG art |
| `GradientCoverTitle` | White title sized to the cover via `cqw`                    |

- The SVG is `aria-hidden` and uses literal hex palettes so covers look identical in light and dark modes.
