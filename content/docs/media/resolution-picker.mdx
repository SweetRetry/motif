
## Usage

```tsx
import { ResolutionPicker } from "@/components/ui/motif/resolution-picker";

export function Output() {
  const [resolution, setResolution] = useState("2K");

  return (
    <div className="space-y-2">
      <div className="font-medium text-muted-foreground text-xs">
        Resolution
      </div>
      <ResolutionPicker
        aria-label="Resolution"
        onChange={setResolution}
        value={resolution}
      />
    </div>
  );
}
```

- Renders no label; pass `aria-label` alongside your own heading.
- Keep `options` in ascending order: dot counts (2–4 dots) are assigned positionally rather than parsed from labels (two options receive 2 and 4 dots).
- `motion-reduce:transition-none` disables the sliding indicator transition.

## Accessibility

- Renders `role="group"` named by `aria-label` with `<button aria-pressed>` cells; dot glyphs are `aria-hidden`.
