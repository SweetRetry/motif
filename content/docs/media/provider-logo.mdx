## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/provider-logo.json
```

## Usage

```tsx
import { ProviderLogo } from "@/components/ui/motif/provider-logo";

<ProviderLogo className="size-5" provider="bytedance" />;
```

- Marks are inlined from [LobeHub's icon set](https://github.com/lobehub/lobe-icons) (MIT) via `pnpm registry:marks` (`@lobehub/icons-static-svg` is a dev-only dependency).
- Monochrome brands (OpenAI, Anthropic, xAI, Groq, Ollama, Moonshot, Pika, Runway, Black Forest Labs) inherit `currentColor`; colored marks keep their brand colors.
- Every mark renders `aria-hidden`.
