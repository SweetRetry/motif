## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/duration-slider.json
```

## Usage

```tsx
import { DurationSlider } from "@/components/ui/motif/duration-slider";

export function Clip() {
  const [duration, setDuration] = useState("5");

  return (
    <div className="space-y-2">
      <div className="font-medium text-muted-foreground text-xs">Duration</div>
      <DurationSlider
        aria-label="Duration"
        max={15}
        min={1}
        onCommit={setDuration}
        value={duration}
      />
    </div>
  );
}
```

- Renders no label; pass `aria-label` alongside your own heading.
- Keeps in-flight drag state local and fires `onCommit` once on pointer release or key press, snapped to `step`.

<DurationSliderSecondsDemo />

## Accessibility

- Renders `role="slider"` with `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, and `touch-none`.
- `↑` / `→` raise the value by one `step` and `↓` / `←` lower it, firing `onCommit` on each press.
