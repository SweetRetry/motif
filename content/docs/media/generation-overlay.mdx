## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/generation-overlay.json
```

## Usage

```tsx
import { GenerationOverlay } from "@/components/ui/motif/generation-overlay";

export function ImageNode({ run }) {
  const pending = run.phase === "generating";
  const mediaSrc = run.phase === "done" ? run.url : undefined;

  return (
    <GenerationOverlay
      id={run.nodeId}
      pending={pending}
      mediaSrc={mediaSrc}
      prompt={run.prompt}
    >
      {mediaSrc ? (
        <img src={mediaSrc} alt="" className="h-full w-full object-cover" />
      ) : null}
    </GenerationOverlay>
  );
}
```

Use `overlay` to mount custom controls such as a retry bar or toolbar:

```tsx
<GenerationOverlay
  pending={pending}
  mediaSrc={mediaSrc}
  overlay={failed ? <RetryBar onRetry={retry} /> : null}
>
  {children}
</GenerationOverlay>
```

## Reveal & Seeds

- Keeps children hidden and `inert` while `pending` is `true` or until `useMediaReveal` finishes (`img.decode()`, `loadeddata` on video, `loadedmetadata` on audio) via capture-phase listeners.
- `seed` defaults to `id` and hashes deterministically so concurrent nodes animate independently without hydration mismatches.

| Seeded by `seed` | Range                                |
| ---------------- | ------------------------------------ |
| Start angle      | 0–360°, per layer                    |
| Layer separation | Second layer 120–240° from the first |
| Direction        | Clockwise or counter-clockwise       |
| Spin             | ~4.5–6s and ~6.5–8.5s                |
| Focal points     | One of five diagonal pairs           |

## Accessibility

- `aria-busy` tracks loading state on the root, and gradient layers are `aria-hidden`.
- `prefers-reduced-motion` pauses gradient rotation and makes the reveal instantaneous.
