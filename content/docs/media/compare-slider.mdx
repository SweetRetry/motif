## Usage

```tsx
import {
  CompareSlider,
  CompareSliderAfter,
  CompareSliderBefore,
  CompareSliderHandle,
  CompareSliderLabel,
} from "@/components/ui/motif/compare-slider";

export function Upscale() {
  return (
    <CompareSlider className="aspect-[3/4] max-w-xs">
      <CompareSliderAfter>
        <img
          alt="Upscaled"
          className="size-full object-cover"
          src="/after.webp"
        />
        <CompareSliderLabel>Upscaled</CompareSliderLabel>
      </CompareSliderAfter>
      <CompareSliderBefore>
        <img
          alt="Original"
          className="size-full object-cover"
          src="/before.webp"
        />
        <CompareSliderLabel>Original</CompareSliderLabel>
      </CompareSliderBefore>
      <CompareSliderHandle label="Compare original and upscaled" />
    </CompareSlider>
  );
}
```

## Parts

| Part                  | Role                                                   |
| --------------------- | ------------------------------------------------------ |
| `CompareSlider`       | Frame container, pointer capture, and divider position |
| `CompareSliderBefore` | Layer clipped left of the divider                      |
| `CompareSliderAfter`  | Base layer right of the divider                        |
| `CompareSliderLabel`  | Corner label inside a layer                            |
| `CompareSliderHandle` | Divider line, grip, and keyboard slider control        |
| `useCompare`          | Hook exposing the current divider position             |

- Both layers fill the frame and should share an aspect ratio; `className` on `CompareSlider` overrides the default `aspect-video`.
- Pressing anywhere on the frame drags the divider; `touch-action: pan-y` preserves vertical page scrolling.

## Without a handle

Omitting `CompareSliderHandle` removes keyboard control while keeping pointer drag; use `useCompare` or external controls to manage position.

## Accessibility

- `CompareSliderHandle` renders `role="slider"` valued in percent (`aria-label` via `label`).
- `ArrowLeft` / `ArrowRight` move 1%, `Shift` + Arrow moves 10%, and `Home` / `End` jump to either edge.
