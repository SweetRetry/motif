## Usage

```tsx
import {
  ModelSelect,
  ModelSelectContent,
  ModelSelectIndex,
  ModelSelectList,
  ModelSelectSearch,
  ModelSelectTrigger,
} from "@/components/ui/motif/model-select";

export function Generation() {
  const [model, setModel] = useState("seedance-2-5");

  return (
    <ModelSelect
      models={MODELS}
      onValueChange={setModel}
      providers={PROVIDERS}
      value={model}
    >
      <ModelSelectTrigger />
      <ModelSelectContent>
        <ModelSelectSearch />
        <div className="flex min-h-0 flex-1">
          <ModelSelectIndex />
          <ModelSelectList />
        </div>
      </ModelSelectContent>
    </ModelSelect>
  );
}
```

## Behavior

- Models with `recommended: true` appear in the top section (`recommendedLabel`, `recommendedHint`, `recommendedIcon`) as well as their provider section.
- `providers` (`{ id, name, icon }`) orders sections and populates `ModelSelectIndex`; icons pair with [Provider Logo](/docs/media/provider-logo) and fall back to the provider's initial.
- Clicking a rail item scrolls to that section and clears any active search rather than filtering the list; `prefers-reduced-motion` jumps without smooth scrolling.
- Search uses [`cmdk`](https://cmdk.paco.me) and `command-score` subsequence matching across `name`, provider, `description`, and `keywords`.

## Item props

| Prop          | Description                                               |
| ------------- | --------------------------------------------------------- |
| `description` | Secondary line below the name                             |
| `meta`        | Trailing slot beside the name (duration, badges, pricing) |
| `keywords`    | Extra searchable terms not rendered on screen             |

## Parts

| Part                 | Role                                                                |
| -------------------- | ------------------------------------------------------------------- |
| `ModelSelectTrigger` | Trigger button; `children` replaces the default face                |
| `ModelSelectContent` | Floating panel surface                                              |
| `ModelSelectSearch`  | Search input synced with root state                                 |
| `ModelSelectIndex`   | Provider jump rail; omit for a plain searchable list                |
| `ModelSelectList`    | Scrollable list, section headings, and active-section spy           |
| `ModelSelectSection` | Section wrapper; `children` replaces the rows                       |
| `ModelSelectItem`    | Model row; `children` replaces the row content                      |

Omit `ModelSelectIndex` for short catalogues:

## Accessibility

- Uses `cmdk` combobox / `role="listbox"` / `role="option"` semantics with `aria-activedescendant`.
- Rail buttons mark the visible section with `aria-current="true"`, and all provider marks are `aria-hidden`.
