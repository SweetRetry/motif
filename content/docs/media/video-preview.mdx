```bash
npx shadcn@latest add https://motif.sweetretry.com/r/video-preview.json
```

## Usage

```tsx
import {
  VideoPreview,
  VideoPreviewFilmstrip,
  VideoPreviewPlayOverlay,
  VideoPreviewScreen,
  VideoPreviewTime,
} from "@/components/ui/motif/video-preview";

export function Take() {
  return (
    <VideoPreview src="/take-3.mp4">
      <VideoPreviewScreen>
        <VideoPreviewPlayOverlay />
      </VideoPreviewScreen>
      <VideoPreviewFilmstrip label="Seek take 3">
        <VideoPreviewTime className="absolute right-1.5 bottom-1.5 rounded-md bg-black/60 px-1.5 py-0.5 text-white" />
      </VideoPreviewFilmstrip>
    </VideoPreview>
  );
}
```

## Parts

| Part                      | Role                                                                |
| ------------------------- | ------------------------------------------------------------------- |
| `VideoPreview`            | Root clock provider and vertical stack                              |
| `VideoPreviewScreen`      | `<video>` frame; children render over the video                     |
| `VideoPreviewPlayOverlay` | Centered play/pause overlay on the screen                           |
| `VideoPreviewFilmstrip`   | Frame-strip scrubber; children render with `pointer-events-none`    |
| `VideoPreviewPlayButton`  | Standalone play/pause button                                        |
| `VideoPreviewTime`        | `m:ss.d` time readout                                               |
| `useVideoPreview`         | Hook exposing `currentTime`, `duration`, and playback state         |

- `VideoPreviewFilmstrip` seeks an off-screen `<video>` to draw frames into a `<canvas>` without requiring CORS headers; seeking still works before frames load or on unseekable files.
- `VideoPreviewScreen` forwards `<video>` props (`muted`, `poster`, `loop`, etc.), loops by default (`loop={false}` disables), and toggles play/pause on click.
- `VideoPreviewTime` formats `m:ss.d`; read `currentTime` and `duration` from `useVideoPreview` for custom formats.

## Arranging the controls

Controls below the strip:

```tsx
<VideoPreviewScreen />
<VideoPreviewFilmstrip />
<div className="flex items-center gap-3">
  <VideoPreviewPlayButton />
  <VideoPreviewTime />
</div>
```

Inline button beside the strip:

```tsx
<VideoPreviewScreen />
<div className="flex items-center gap-3">
  <VideoPreviewPlayButton />
  <VideoPreviewFilmstrip className="flex-1" />
</div>
```

## Accessibility

- `VideoPreviewFilmstrip` renders `role="slider"` valued in seconds (`Arrow` moves 1s, `Shift` + Arrow moves 5s, `Home` / `End` jump to ends).
- Customize accessible names with `label` on the strip and `playLabel` / `pauseLabel` on `VideoPreviewPlayButton`.
