## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/strength-slider.json
```

Installs the `strength-mote` CSS keyframe into your stylesheet.

## Usage

```tsx
import { StrengthSlider } from "@/components/ui/motif/strength-slider";

export function Defaults() {
  const [strength, setStrength] = useState("Medium");

  return (
    <div className="space-y-2">
      <div className="font-medium text-muted-foreground text-xs">Strength</div>
      <StrengthSlider
        aria-label="Strength"
        onChange={setStrength}
        value={strength}
      />
    </div>
  );
}
```

- Renders no label; pass `aria-label` alongside your own heading.
- Pass `options` in ascending order (weakest first); the last option displays the `strength-mote` drift animation (omitted under `prefers-reduced-motion`).
- Dragging or clicking any seat or label commits immediately via `onChange` on each crossing.

## Accessibility

- Renders `role="slider"` with `aria-label`, index-based `aria-valuenow`, `aria-valuetext` for the level name, and `touch-none` (seat labels and motes are `aria-hidden`).
- `↑` / `→` move stronger, `↓` / `←` move weaker, and `Home` / `End` jump to either end.
