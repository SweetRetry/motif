## Installation

```bash
npx shadcn@latest add https://motif.sweetretry.com/r/flow-edge.json
```

## Usage

```tsx
import { FlowEdge } from "@/components/ui/motif/flow-edge";

export function Connector({ running }: { running: boolean }) {
  return <FlowEdge active={running} className="text-primary" />;
}
```

The `<svg>` scales to its container width and derives its color from `currentColor`.

## States

| `active` | Renders                                       |
| -------- | --------------------------------------------- |
| `false`  | Dimmed idle line at quarter opacity           |
| `true`   | Repeated lit pulse travelling from start to end |

## Geometry

Pass `d` and `viewBox` together so the mask and halo travel match the path; `d` should be monotonic in `x`.

```tsx
<FlowEdge
  active={running}
  d="M 0 60 C 40 60 40 0 80 0"
  viewBox="0 0 80 60"
  className="text-primary"
/>
```

## Props

| Prop          | Default | Description                                                  |
| ------------- | ------- | ------------------------------------------------------------ |
| `duration`    | `1400`  | Duration of one pass in milliseconds                         |
| `rest`        | `0.28`  | Fraction of the cycle parked between passes (`0` streams)    |
| `streak`      | `0.2`   | Pulse length as a fraction of `viewBox` width                |
| `strokeWidth` | `3.5`   | Lit stroke width in user units (halo is `2x`)                |
| `glow`        | `2.5`   | Halo blur radius in user units (`0` disables the halo)       |

## CSS variables

`--edge-core`, `--edge-glow`, and `--edge-track` all default to `currentColor` and can be overridden on a wrapper:

```tsx
<div
  className="text-[oklch(0.769_0.117_261.6)]"
  style={{ "--edge-core": "oklch(0.966 0.016 262.8)", "--edge-track": "#fff" }}
>
  <FlowEdge active={running} />
</div>
```

## Accessibility

- The `<svg>` is `aria-hidden`; pair it with adjacent status text when conveying progress.
- Under `prefers-reduced-motion`, animation stops and the pulse rests at mid-run.
