# Docs

`docs/` 回答“这是什么”和“怎么用”，是面向开发者和 Agent 的系统知识库。

适合记录：

- 本地开发、构建、发布和故障排查指南
- registry / 文档站 / 组件源码三者的结构说明
- 需要跨多个源码模块理解的功能文档

重大架构取舍写入 `adr/`，强制执行的工程约束写入 `rules/` 或根目录 `AGENTS.md`，可执行自动化写入 `scripts/`。
